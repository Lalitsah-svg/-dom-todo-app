# TaskFlow - To-Do Application

TaskFlow is a responsive task management application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter all, active, and completed tasks
- Search tasks
- Clear completed tasks
- Automatic localStorage saving
- Restore tasks after browser refresh
- Responsive desktop and mobile interface
- Task statistics and progress indicator

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start adding tasks.

No installation or external backend is required.

## Data Storage

Tasks are stored locally in the browser using localStorage.
